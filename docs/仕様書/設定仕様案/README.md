# **目的**

- ユーザーの身体情報・目標を管理し、AI献立生成の精度を高める
- 食の好み・アレルギーを設定し、安全で続けやすい献立を実現する
- プロフィールをいつでも編集可能にし、状況の変化に対応できるようにする

---

# **UI構成**

縦スクロールでセクション分けされたリスト表示

### **セクション一覧**

- プロフィール
- 目標設定
- 食の好み・アレルギー

---

# **プロフィール**

## **表示内容**

- 性別
- 年齢
- 身長（cm）
- 体重（kg）
- 活動量（低・中・高）

---

## **編集モーダル**

### **入力項目**

- 性別（選択式：男性 / 女性 / その他）
- 年齢（数値入力）
- 身長（数値入力・cm）
- 体重（数値入力・kg）
- 活動量（選択式：低 / 中 / 高）

### **アクション**

- 保存
- キャンセル

---

## **保存時の挙動**

- 即時UIに反映
- 基礎代謝・推奨カロリーを再計算

---

# **目標設定**

## **表示内容**

- 目標体重（kg）
- 目標達成期間（ヶ月）
- 現在の体重との差分

---

## **編集モーダル**

### **入力項目**

- 目標体重（数値入力・kg）
- 目標達成期間（数値入力・1〜24ヶ月）

### **アクション**

- 保存
- キャンセル

---

## **保存時の挙動**

- 即時UIに反映
- 目標体重と期間に基づいて、健康的な減量ペースで推奨カロリーを再計算
- 月あたりの目標減量ペースを算出

---

# **食の好み・アレルギー**

## **表示内容**

- 嫌いな食べ物（タグ一覧）
- アレルギー食材（タグ一覧）

---

## **編集モーダル**

### **入力項目**

- 嫌いな食べ物（テキスト入力 → タグ追加）
- アレルギー食材（テキスト入力 → タグ追加）

### **タグ操作**

- 入力確定でタグ追加
- タグタップで削除

### **アクション**

- 保存
- キャンセル

---

## **保存時の挙動**

- 即時UIに反映
- 次回以降の献立生成で除外対象に反映

---

# **UX意図**

| **要素**               | **役割**       | **ユーザー心理**             |
| ---------------------- | -------------- | ---------------------------- |
| プロフィール           | 基礎情報管理   | 自分に合った提案をしてくれる |
| 目標設定               | モチベーション | ゴールが見えると続けやすい   |
| 食の好み・アレルギー   | 安全性・継続性 | 嫌いなものが出ないから安心   |
| 即時反映               | フィードバック | 変更がすぐ反映される信頼感   |
