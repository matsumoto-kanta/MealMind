# **目的**

- 過去の献立を振り返れる

---

# **UI構成**

## **日付ごとのアコーディオンリスト**

縦スクロールで日付を表示

タップでその日の献立を展開

---

## **アコーディオン展開時**

### **表示内容**

その日の献立カードを表示（朝 / 昼 / 夜）

### **各カード**

- 料理名
- kcal
- コスト

---

## **カードタップ時**

### **詳細モーダル**

- 食材内訳
- PFC詳細

→ 当日の「確定状態」を再現

---

## **表示ルール**

### **並び順・取得仕様**

- 履歴は **新しい日付が上（降順）** に並ぶ
- 一定件数ずつ段階的に取得する **無限スクロール方式** を採用
- 画面下端に到達したタイミングで、次の履歴データを自動取得する

### **保存単位**

- 1日単位で保存
- 確定したものだけ履歴に残る

---

# **UX意図**

| **要素**           | **役割** | **ユーザー心理**   |
| ------------------ | -------- | ------------------ |
| 日付アコーディオン | 情報整理 | 見たい日だけ開く   |
| カード一覧         | 即時理解 | ざっと振り返る     |
| 詳細モーダル       | 深掘り   | 内容確認           |
| 再利用ボタン       | 行動誘導 | 考える手間を減らす |
