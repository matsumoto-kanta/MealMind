# **目的**

- 1日の食事（朝・昼・夜）をAIが自動提案
- 予算と栄養（PFC / kcal）を同時最適化
- 確定後は「行動ベースのUI」に切り替える

---

# **未確定フェーズ（Draft）**

## **UI構成**

縦スクロールで3カード表示（朝 / 昼 / 夜）

### **各カードに表示する情報**

- 料理名
- 想定カロリー
- PFCバランス
- 想定コスト
- 食材（量・単価）

### **ボタン**

- 別案を再生成（その食事のみ）
- この食事を確定

---

# **確定フェーズ（Fixed）**

## **UI変更**

- 3食を横スクロールカードに変更
- 情報は簡易化

### **表示項目（カード）**

- 料理名
- kcal
- コスト

### **タップ時**

- 食材内訳
- PFC詳細
- 栄養コメント（将来）

---

# **確定後に表示される下部エリア**

## **買い物リスト**

- 3食分の食材を統合
- 合計金額表示
- 重複まとめ

---

## **再調整ボタン**

- 朝だけ変更
- 昼だけ変更
- 夜だけ変更
- 全体を再生成

---

# **UX意図**

| **状態** | **UI** | **ユーザー心理** |
| -------- | ------ | ---------------- |
| Draft    | 縦     | 比較・選択       |
| Fixed    | 横     | 今日の確定行動   |
| 下部     | リスト | 買い物まで完結   |
