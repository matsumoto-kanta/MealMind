# **目的**

- シンプルで素早いログイン体験を提供
- Googleアカウントで手軽に始められるようにする
- ユーザー管理の煩雑さを減らし、サービス利用のハードルを下げる

---

# **UI構成**

## **ログイン画面**

### **表示要素**

- アプリロゴ
- キャッチコピー / 説明文
- Googleログインボタン

### **レイアウト**

- 中央配置
- ミニマルなデザイン
- モバイルファースト

---

# **ログインフロー**

## **ログイン時**

1. Googleログインボタンをタップ
2. Google OAuth画面に遷移（自動ログインの場合はスキップ）
3. Googleアカウントを選択
4. 認証完了
5. メイン画面に遷移
   - 設定データがnullの場合は自動で設定タブに遷移

---

# **認証方式**

## **Google OAuth 2.0**

- フロントエンド: `@react-oauth/google` 使用
- バックエンド: Google Identity Platform で検証

### **取得する情報**

- ユーザーID（Google sub）
- メールアドレス
- 名前（表示用・任意）
- プロフィール画像（表示用・任意）

---

# **セッション管理**

## **トークン保存**

- アクセストークン: HTTPOnly Cookie
- リフレッシュトークン: HTTPOnly Cookie（セキュア）
- ローカルストレージには保存しない

## **有効期限**

- アクセストークン: 1時間
- リフレッシュトークン: 30日間
- 自動更新機能あり

---

# **ログアウト**

## **フロー**

1. 設定画面からログアウトボタンをタップ
2. 確認ダイアログ表示
3. OKでトークン削除
4. ログイン画面に遷移

---

# **エラーハンドリング**

## **想定エラー**

| **エラー内容**         | **ユーザーへの表示**                         | **対処**                 |
| ---------------------- | -------------------------------------------- | ------------------------ |
| 認証キャンセル         | ログイン画面に戻る                           | 再度ログイン可能         |
| ネットワークエラー     | 「ネットワーク接続を確認してください」       | リトライボタン表示       |
| サーバーエラー         | 「一時的なエラーが発生しました」             | リトライボタン表示       |
| トークン有効期限切れ   | 自動で再ログイン                             | ユーザーには見せない     |
| Google側のエラー       | 「Googleログインに失敗しました」             | しばらく待ってリトライ   |

---

# **セキュリティ**

## **対策**

- HTTPS必須
- CSRF対策（トークン検証）
- XSS対策（サニタイジング）
- HTTPOnly Cookie でトークン保護
- Same-Site Cookie 設定

---

# **UX意図**

| **要素**               | **役割**           | **ユーザー心理**                       |
| ---------------------- | ------------------ | -------------------------------------- |
| Googleログイン         | 手軽さ             | パスワード不要で楽                     |
| ミニマルUI             | シンプルさ         | 迷わない、すぐ始められる               |
| 設定自動遷移           | スムーズさ         | 必要なステップが自然に案内される       |
| エラーメッセージ       | 安心感             | 何が起きたか分かる、対処法が分かる     |
| 自動トークン更新       | ストレスフリー     | ログイン状態が維持される               |
